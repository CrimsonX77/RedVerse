About

A desktop speech-to-text tool for real-time dictation. Multiple backend support — Google Cloud STT, Whisper, or system speech recognition. Clipboard integration with history and favorites. Continuous listening mode for hands-free operation. For when typing out giant novels of information isn't an option.

Features
  • Multiple STT backends: Google Cloud, Whisper, System
  • Real-time continuous transcription
  • Clipboard history with search
  • Favorites for frequently used phrases
  • Continuous listening mode — hands-free operation
  • Export transcriptions to TXT/MD files
Tech Stack
Python PyQt6 SpeechRecognition Whisper Google Cloud STT
